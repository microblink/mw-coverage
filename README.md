# Microblink SDK coverage badges

Public storage for minimal
[Shields endpoint](https://shields.io/badges/endpoint-badge) payloads. Coverage
is informational and is not a quality gate.

Each `badges/<opaque-id>.json` file contains only the label, displayed
percentage, color, and Shields schema version. Opaque identifiers let
repositories publish independently without encoding source repository names in
badge paths.

Detailed coverage reports, source repository metadata, commit identifiers,
workflow URLs, package metrics, and covered totals must not be stored in this
repository. Detailed reports remain in the authenticated Actions data of the
repository that produced them.
